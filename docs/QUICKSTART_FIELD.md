# GeoLog Field Quickstart
1. Upload LAS (`Upload LAS`)
2. Add tops (`Interpret -> Tops` or double-click on track)
3. Add zones (`Petrophysics -> Auto Zone from Tops`)
4. Run interpretation (`Compute Sw`, `Multimineral`, `VClay QC`)
5. Export (`Export LAS`, `Report PDF`, `SVG`, `Batch Export`)

## Keyboard
- G/R/P: toggle GR/RT/NPHI
- Arrow Up/Down: scroll depth
- Page Up/Down: page move
- +/-: zoom in/out
- Home/End: jump start/end
