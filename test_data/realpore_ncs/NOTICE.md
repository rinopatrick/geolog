# RealPore NCS core fixture — provenance and licence

Subset (300 consecutive plug rows with porosity + Klinkenberg permeability +
fluid-saturation triplets, well 35/11-7) from:

Geoprovider / Bormann, P. (2021). Porosity, Permeability, Rock Type data
from 1240 Norwegian exploration, appraisal and development wells. Core data.
Zenodo. https://zenodo.org/records/4419060 (Version v1; also v2 at
https://zenodo.org/records/4723018)

Source data originate from NPD Diskos (NOLD 2.0); 600+ well datasets were
hand-digitised. Lithology descriptions are transcribed as-is and the
translation to geological terms is incomplete per the source readme.

Use in GeoLog: validate log-derived PHIE/perm transforms and Sw baselines
against laboratory plug measurements — the missing core-lab leg of the
petrophysics production-grade claim. NOT checkshot-calibrated, NOT SCAL
capillary pressure: no Pc curves in this subset.
